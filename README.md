# KMPC Website Assets

This folder contains all images used in the KMPC website.

## Images to Add

### 1. kmpc-logo.png
- **Location**: Used in the navigation header as the brand icon
- **Dimensions**: 48x48px or larger (square format recommended)
- **Format**: PNG (transparent background preferred) or SVG
- **Description**: KMPC logo for the navigation bar
- **How to add**: Save your logo as `kmpc-logo.png` in this folder

### 2. team-photo.jpg
- **Location**: This file is referenced in the hero section
- **Dimensions**: Ideally 400-500px wide, 500-600px tall (portrait orientation)
- **Description**: The KMPC team group photo
- **How to add**: Save your team photo as `team-photo.jpg` in this folder

### 3. vision-mission-board.jpg
- **Location**: Displayed in the Vision, Mission & Goals section
- **Dimensions**: Ideally 800-1000px wide (can be any height)
- **Description**: Your KMPC whiteboard with Vision, Mission, and Goals
- **How to add**: Save your vision board photo as `vision-mission-board.jpg` in this folder

## Steps to Complete

1. Download or save your two images
2. Place them in this `assets/` folder
3. Rename them exactly as shown above (case-sensitive on some systems)
4. Open `kerdos_rebuilt.html` in your browser to verify the images appear correctly

## Troubleshooting

If images don't show:
- Check file names match exactly: `team-photo.jpg` and `vision-mission-board.jpg`
- Ensure files are in the `assets/` folder, not elsewhere
- Try refreshing the browser (Ctrl+F5 or Cmd+Shift+R)
- Check browser console for any error messages
